# Zenvio Roofing website

Next.js (App Router) + Tailwind CSS marketing site for Zenvio roofing.

- Edit business details, services, reviews, FAQs and stats in `src/lib/site.ts`.
- Replace photos in `public/images/` with your own project photos (keep the same file names, or update the paths in `site.ts`).
- The quote form opens WhatsApp with the request pre-filled, with an email fallback.

```bash
npm install
npm run dev
```

Deploys automatically on Vercel when pushed to GitHub.
